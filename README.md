## Web Application Security

### SQLi Tools
* [Gatotkaca](https://github.com/N1ght420/Gatotkaca) - Advanced SQL injection scanner and exploitation tool
* [MadDrozer](https://github.com/Amriez/MadDrozer) - SQL injection vulnerability scanner with automatic database extraction

### Web Scanners
* [Nusantara](https://github.com/indosecid/nusantara) - Automated web vulnerability scanner with Indonesian-focused payloads
* [B3604-Scanner](https://github.com/kevinsubagio/B3604-Scanner) - Multi-threaded web vulnerability scanner written in Python
* [Pegasus-Scan-Web-Total](https://github.com/sobri3195/Pegasus-Scan-Web-Total) - A comprehensive web security scanner that can detect various vulnerabilities in web applications

* [JoomScan-JM](https://github.com/rezasp/joomscan) - Joomla vulnerability scanner and exploitation tool
